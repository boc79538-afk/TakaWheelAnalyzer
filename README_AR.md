# Taka Wheel Analyzer — النسخة الأولى

تطبيق Android مستقل باللغة العربية، بألوان بنفسجية وذهبية، ويحفظ البيانات محلياً على الهاتف.

## ما الذي يعمل في هذه النسخة؟
- شاشة رئيسية.
- محاكاة دوران عشوائي مستقلة.
- إدخال نتيجة ظهرت فعلياً في تطبيق تاكا يدوياً.
- تحليل تكرار الجوائز ونسبها ضمن النتائج الحقيقية المسجلة.
- سجل محلي مع إمكانية مسحه.
- لا يحتاج إلى إنترنت ولا يطلب صلاحيات حساسة.

## حدود مهمة
هذا التطبيق لا يتصل بخوادم Taka ولا يقرأ حسابك ولا يضيف كوينز ولا يغيّر نتائج العجلة. المحاكاة ليست توقعاً لنتائج تاكا. تحليل النسب يعتمد فقط على النتائج التي تدخلينها.

## إنشاء APK
1. ثبّتي Android Studio على الكمبيوتر.
2. فكّي ضغط الملف وافتحي مجلد `TakaWheelAnalyzer` عبر **Open**.
3. انتظري مزامنة Gradle وتنزيل مكونات Android المطلوبة.
4. اختاري **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. عند النجاح سيظهر APK في:
   `app/build/outputs/apk/debug/app-debug.apk`

## متطلبات البناء
- Android Studio حديث.
- JDK 17 أو أحدث.
- Android SDK Platform 35.
- اتصال إنترنت أول مرة لتنزيل Gradle والمكتبات.

الحد الأدنى للنظام: Android 6.0 (API 23).
